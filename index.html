TMDB API key

Cinephile gets titles, posters and details from TMDB. Paste your own free key (the short API Key or the long API Read Access Token). Get one at themoviedb.org/settings/api (free account required).

The key is stored only on this computer, in the app's local storage. That is convenient but is not a secure vault, so use a key you can revoke.

This product uses the TMDB API but is not endorsed or certified by TMDB.
